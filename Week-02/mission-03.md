# Mission 3 - Is It Really AI?

## Objective

The objective of this mission is to understand that not every smart-looking application is Artificial Intelligence. Some systems only follow fixed rules, while others learn from data or generate new content.

## Answer

Not everything that does a job is Artificial Intelligence software. Traditional software is written by programmers according to set rules, so that the same input will always produce the same output. Machine Learning systems are unusual in that they learn the patterns from the data and enhance their performance without the need to write every rule manually. Generative AI takes it farther, generating new things – text, graphics, code or videos – from the patterns it acquired during training.

The key difference, when comparing these examples, is the working of the system. If it just follows prescribed rules, it’s traditional software. Machine learning refers to the process where it learns from data patterns. If it produces fresh content, it is Generative Artificial Intelligence. This helped me to realize why not every smart application is AI.

## Classification Table

| Example | Classification | Reason |
|---------|---------------|--------|
| Calculator | Rule-based / Traditional Software | Uses fixed mathematical rules written by programmers. |
| Temperature Warning Rule | Rule-based / Traditional Software | Displays a warning only when a predefined condition is met. |
| Gmail Spam Filter | Machine Learning-based AI | Learns patterns from previous spam and non-spam emails. |
| Document Summarizer | Generative AI | Generates a new summary from the given document. |
| Traffic ETA Prediction | Machine Learning-based AI | Predicts travel time using traffic and historical data. |

## Easy Classification

The calculator was the easiest example because it always follows fixed mathematical rules and never learns from data.

## Difficult Classification

Traffic ETA prediction was slightly difficult because it looks like a normal calculation. After learning more, I understood that it uses Machine Learning to analyze traffic patterns and historical data before predicting the travel time.

## My Own Example

**Netflix Movie Recommendation**

**Classification:** Machine Learning-based AI

**Reason:** Netflix learns from my watching history and recommends movies based on my interests instead of following fixed rules.

## Conclusion

This mission helped me understand the difference between traditional software, Machine Learning, and Generative AI. I also learned that before calling something AI, I should first understand how it actually works.
