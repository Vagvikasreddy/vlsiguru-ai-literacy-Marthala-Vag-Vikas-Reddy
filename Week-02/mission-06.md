# Mission 6 - Chatbot or Agent?

## Objective

The objective of this mission is to understand the difference between a Large Language Model (LLM), an AI application, a RAG system, a tool-using assistant, and an AI Agent. This helped me understand that not all AI systems work in the same way and that an AI Agent can perform much more than just answering questions.

## Answer

A **Large Language Model (LLM)** is an AI model that understands and generates human language. It is trained on a large amount of data and can answer questions, explain concepts, write content, and generate code. An **AI application** is software that uses an LLM to interact with users. ChatGPT is a good example because it uses a Large Language Model to answer questions and generate responses.

A **RAG (Retrieval-Augmented Generation)** system improves an LLM by retrieving information from external documents or databases before generating the answer. This helps provide more relevant and up-to-date information. A **tool-using assistant** is an AI system that can use external tools such as web search, calculators, calendars, or databases while answering a user's request. An **AI Agent** goes one step further by planning multiple steps, using tools, making decisions, and completing a goal instead of simply generating a response.

## Comparison Table

| Concept | Description | Example |
|---------|-------------|---------|
| LLM | AI model that understands and generates language | GPT |
| AI Application | Software that uses an LLM | ChatGPT |
| RAG System | Retrieves external information before answering | AI assistant searching company documents |
| Tool-Using Assistant | Uses external tools to complete tasks | AI using web search or a calculator |
| AI Agent | Plans tasks, uses tools, and completes goals | AI travel booking assistant |

## Everyday Example

A travel booking assistant is a good example of an AI Agent. If I ask it to book a flight, it can search for available flights, compare prices, select the best option, complete the booking, and send a confirmation email. A normal chatbot would only answer questions about flights, but an AI Agent can complete the entire task.

## Conclusion

This mission helped me understand that an LLM is the language model itself, an AI application uses the model, a RAG system retrieves additional information, a tool-using assistant can access external tools, and an AI Agent combines all these capabilities to complete a goal.
